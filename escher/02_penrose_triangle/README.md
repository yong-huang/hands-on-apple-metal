# 02 · Penrose 三角：用深度差织出闭环

> 用三片 120° 折梁（V 形片）沿视线分层搭接，拼出经典"不可能三角"——每片
> 占一角两半边，边中点处进片的端头搭在出片上，绕环轮转、闭合却不可能。读完
> 本篇你能掌握搭接的深度构造、三色调轮转的着色方案，以及断裂角的公差推导。

## Background

画家表现立体靠深度线索（depth cue，人眼判定远近的依据）：遮挡、近大远小、
明暗。把线索画得自洽，就得到可信的立体；把线索组织得彼此矛盾，就得到
"不可能图形"。

1934 年瑞典艺术家 Oscar Reutersvärd 首先画出不可能三角；1958 年物理学家
Roger Penrose 父子独立再发现并推广它，Escher 据此画出《瀑布》（Waterfall,
1961）。

二维画骗局好造，三维实物却造不出：想把三根梁真的连成闭环，深度必然在某处
穿帮。玩具与雕塑行业的解法是"诈骗雕塑"——用几个真实零件 + 唯一观测角度，
让投影恰好闭合。本实验把这套手法搬进 Metal：不是画一幅图，而是真的建三根
梁，让相机来行骗。

## What

Penrose 三角实验是一种"角度依赖的错觉物体"：三片 120° 折梁沿视线分层——
每片占一个角与两条半边，层间差 μ=1.2。正交投影（无近大远小的平行投影）下
沿视线分层不改变画面，三片在魔法角度下严丝合缝地拼成一只三角环。

拼合的缝在三条边的中点：进片的端头（近）搭在出片的臂上（远）——三个中点
都是"上一片压着下一片"，绕环轮转。局部处处合理，整体却是一只永远走不到头
的闭环。

## When to Use

- **装置与雕塑设计**：真实存在的不可能物体（Perth 的 impossible triangle
  雕塑即同款原理）
- **错觉教学**：一屏讲清"遮挡线索 + 观测角度"如何合谋骗过深度知觉
- **插画与图形设计**：等距风格（isometric，各轴等比例、无近大远小）不可能
  图形的参数化绘制

何时不用：需要真实遮挡与自由视角的常规 3D 场景——那里的正解是透视相机加
深度缓冲（depth buffer，逐像素记录"离相机最近的是谁"的显存）。

| 方案 | 差异 | 什么时候选它 |
|:---|:---|:---|
| 二维插画 | 画什么是什么，无角度约束 | 平面媒介 |
| 真 3D 闭环三角 | 物理不存在 | —— |
| 诈骗雕塑（多零件 + 魔法角度） | 真实存在，仅单角度闭合 | 装置、展品 |
| **正交渲染的参数化诈骗** | 零件尺寸与断裂角全部可调 | 本实验：错觉演示 |

## Quick Start

前置条件：装好 Xcode Command Line Tools（`xcode-select --install`）；Metal 为系统自带。

```bash
./penrose.sh                 # 一条龙：build → observe → clean
./penrose.sh observe         # 自由旋转+滚轮缩放；偏出 ±19° 即断口；F 换层间差；「重置」
AUTO_QUIT=6 ./penrose.sh     # 6 秒自动退出（脚本化验证）
./penrose.sh export out.png open   # open=断口视角；closed=魔法角度（默认）
```

## How It Works

**三片折梁：搭接的构造。** 每片是 120° 的 V 形平面片：占一个角、两条臂各
伸半边加一段搭接量，正面按"外半暗、内半亮"上色。三片沿视线方向分层（层间
差 μ）——正交投影下深度不显示，三片的画面严丝合缝拼成三角环。

拼合的缝在三条边的中点：进片的臂端（近）搭在出片的臂上（远），进片的角块
色调与出片不同——织接处处可见：每片都压着下一片，绕环轮转，永远闭环。

**带深度的管线：织接靠遮挡。** 与 Necker 立方体（见 escher/01_necker_cube）刻意抹掉深度相反，织接的
前后关系正是错觉的核心机制：投影矩阵多一行把视深压进深度范围，深度测试
（每像素 16 位的 depth16Unorm 缓冲判定"谁在前"）让角点端面真实压住下一根梁。

**三色调轮转：立体感的来源。** 每片正面按"臂外半暗、臂内半亮"上色，三片
旋转 120° 叠放后，三条边的明暗半区随之轮转；边中点的搭接处，进片的色调与
出片不同——缝因此可见。这正是原画"局部合理的明暗 + 整体矛盾的绕环"的
着色语言。

**接缝断裂角 ≈ asin(w/2μ)。** 相机偏转小角 α 时，边中点处进片端头与出片
的投影相对错开约 μ·sinα（层间差 μ）。错开超过半条梁宽 w/2，缝就露出、
三片分离——α ≈ asin(w/2μ)。本实验 w=0.8、μ=1.2，断裂角 ≈ 19°，窗口标题
在偏出 19° 时提示"已穿帮"。

## Pitfalls & Q&A

- **梁变成斜棱柱**：现象是梁体歪斜、宽度不均。原因：箱体的截面轴传了与长轴
  不正交的矢量（如视线方向）——轴系非正交时拼出的是斜平行六面体。解法：
  截面轴必须由长轴重新正交构造（先叉乘再归一）。
- **角点共面闪烁**：深度跨度 μ 调得太小时，角点处进来的梁端与出去的梁起点
  深度几乎相同，共面片元每帧争夺深度（z-fighting，两块共面小三角形面片
  争夺"谁离相机近"的深度判定）。解法：μ 保留下限（0.4），保证角点两端
  深度差远大于深度缓冲精度。
- **搭接处色调无跳变**：现象是边中点的缝看不出来、错觉"不成立"。原因：
  相邻两片用了同一套明暗配色，重叠区色调相同、织接隐形。解法：三片色调
  按暗/中/亮轮转，每条边的搭接两侧必然异色。

**Q：怎么自己改"断裂角"？** 调 `penrose.swift` 顶部的 `spanLevels`（F 键
循环的层间深度差，默认 1.2/0.6/0.25）：层差越大织接越耐拖，越小一碰就散。
层差趋近 0 时三片共面，深度差消失——错觉随之一起消失。

**Q：它和埃舍尔哪幅作品同源？** 《瀑布》（1961）的水流闭环与《上升与下降》
（1960）的无限楼梯都源自 Penrose 父子的不可能闭环，本实验造的是闭环的
"骨架"。系列项目 4 会用 SDF raymarching（符号距离场光线步进：用"到最近
表面的距离"函数逐像素求出画面）把楼梯闭环真正走进去。
