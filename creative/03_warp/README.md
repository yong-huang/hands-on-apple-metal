# 03 · Domain Warping 壁纸生成器：把噪声"揉"出大理石纹

> 同一段随机噪声，不扭曲时是呆板的云雾斑；让它自己扭曲自己两次，就流成大理石纹与极光带。
> 本实验无窗口、纯导出：一条命令产出 4K 壁纸，换一个 seed 就是一张新图。
> 读完本篇你能掌握值噪声、fbm 叠加与域扭曲这套生成艺术的核心管线。

## Background

程序化生成自然质感有个尴尬的前置问题：随机数本身不好看。把白噪声（每个像素独立随机）直接铺满屏幕，得到的是电视雪花——自然界没有这种"每一点都和邻居无关"的纹理；石头、云、木纹的共同点是**近处相似、远处不同**，且细节层层嵌套。

早期游戏与电影的做法是美术手绘纹理贴图，成本高且变体有限。Perlin 在 1983 年提出梯度噪声，让"平滑的随机"第一次可以按公式廉价生成（他凭这项工作在 1997 年拿下奥斯卡技术成就奖，早期给电影做特效的经历正是其起点）。

之后 fbm（分形布朗运动）把多个倍频程（频率逐层翻倍的噪声层）的噪声叠出细节层次，Inigo Quilez 等人再补上域扭曲——噪声场反过来当坐标偏移——大理石、火焰、极光从此都可以一行公式长出来。

逐像素算 4K 图是 800 万像素 × 25 次值噪声求值（域扭曲要采样 5 次 fbm，每次 fbm 叠 5 个倍频程），量级在 2 亿次；本实验交给片元着色器（GPU 上为每个像素跑一遍、算出该像素颜色的小程序）一次性并行算完。

## What

Domain Warping 是一种噪声加工手法：把采样噪声用的坐标，先用另一张噪声场的输出偏移一次（甚至两次），平直的噪声图被"揉"出流动的纹理，视觉效果接近大理石切面或云层漩涡。

> 🌐 **交互版**：[在线打开（GitHub Pages）](https://yong-huang.github.io/hands-on-apple-metal/creative/03_warp/images/warp.html)（或本地打开 [`images/warp.html`](images/warp.html)）。

可以把值噪声想象成一块"模糊的骰子布"：每个整数格点掷一个随机数，相邻点之间平滑过渡——远处各掷各的，近处连成缓坡。但和真实骰子不同的是，这块布由哈希函数（同一输入永远掷出同一数）生成，所以同一 seed 每次渲染结果完全一致。

## When to Use

- **壁纸与背景素材批量生产**：一条命令一张 4K 图，seed 即编号，可无限出图
- **游戏/3D 场景的地形与云图**：fbm 是高度图和体积云的通用底料，本实验的公式可以直接搬去生成
- **设计稿的氛围底图**：比纯色渐变有质感，比照片素材可控

何时不用：需要精确可控的构图（主体、文字排版）时，噪声是"氛围"不是"内容"，排版类设计请用矢量工具。

| 方案 | 差异 | 什么时候选它 |
|:---|:---|:---|
| 素材网站下载壁纸 | 精致但撞图，且难以系列化 | 只要一张、不求过程 |
| Perlin/Simplex 噪声直接出图 | 一层噪声细节单调，一眼"程序味" | 地形高度图等对纹理要求低的场合 |
| Stable Diffusion 生成 | 语义可控、效果好；模型数 GB、出图秒级到十秒级 | 需要具体内容（物体、场景）时 |
| **fbm + 域扭曲** | 零依赖、毫秒级、seed 可复现；抽象纹理无需提示词调参即可无限系列化 | 本实验：批量抽象壁纸与学习噪声管线 |

## Quick Start

前置条件：装好 Xcode Command Line Tools（`xcode-select --install`）。本实验没有窗口模式——输出就是导出的图片，全程可在终端与文件管理器里完成。

```bash
./warp.sh                        # 一条龙：build → 导出 seed 1/7/42 三张 4K → clean
./warp.sh export out.png         # 导出一张 3840×2160 PNG（默认 seed 1）
./warp.sh export out.png 7.0     # 指定 seed
./warp.sh seeds mywall           # 连出 mywall_1.0/7.0/42.0.png 三张，验收"换 seed 换图"
```

真实输出（`./warp.sh export images/warp_seed1.png 1.0`，成品见 [images/warp_seed1.png](images/warp_seed1.png)）：


- 观察要点：图上是被"揉"出的大理石纹与色带，蓝灰、米白、赭橙与青绿四系交织（青绿正是开头说的"极光带"）；任何一处放大都还有更小的漩涡细节

## How It Works

**像素 → 画布坐标。** 片元着色器拿到的是 fragCoord（像素坐标系下的位置），先减半分辨率居中、除以短边，归一到短边范围 [-0.5, 0.5]——这样导出横屏竖屏纹理密度都一致。乘上噪声缩放 scale 后送进噪声管线。

**值噪声：会插值的骰子布。** `hash` 把每个整数格点映射成 0~1 的伪随机数（含 seed），`valueNoise` 在格点间对周围 4 个格点的随机数做加权平均（双线性插值），并用 smoothstep（一条先缓后缓的平滑曲线）替换生硬的线性过渡，消除格线折痕。

相邻点数值连续、远处无关——"近相似远不同"就满足了。

**fbm：细节是叠出来的。** 一层噪声只是缓坡，把频率翻倍、振幅减半的噪声叠五次（五个倍频程），大形状里长出中细节、中细节里长出小细节——山石、云、大理石的层次都这么来。代价是每个像素 5 次 fbm、合计 25 次值噪声求值，4K 图约 2.1 亿次，全靠 GPU 并行消化。

**域扭曲：噪声揉噪声。** 核心就三行：

```metal
float2 q = float2(fbm(p, seed), fbm(p + float2(5.2, 1.3), seed));
float2 r = float2(fbm(p + strength * q + float2(1.7, 9.2), seed),
                  fbm(p + strength * q + float2(8.3, 2.8), seed));
float f = fbm(p + strength * r, seed);
```

q 是 p 处的噪声向量，把 p 加上 strength×q 再采样得到 r，最后连 f 的采样坐标也被 r 扭过——查询坐标本身被噪声推着走，原本平行的等值线被挤成流动的纹路。你在成品里看到的每一道"大理石纹"，都是一次坐标被推弯的等值线。

**seed 是确定性之源。** seed 进了每一次哈希：换 seed 等于把骰子布整体重掷，三张输出肉眼可辨地不同；不换 seed，噪声纯函数逐位复现，PNG 逐字节相同。

## Pitfalls & Q&A

- **导出全是高频雪花噪点**：现象是图上密密麻麻的颗粒，毫无纹理。原因：忘了把 fragCoord 除以分辨率——像素坐标直接乘 scale，4K 图上噪声频率被放大上千倍。解法：先归一到 [-0.5, 0.5]（本实验的 uv 公式），再乘 scale。
- **着色器报 use of undeclared identifier**：现象是运行时编译失败，报 `u1` 未定义。
  原因：uniform（每次绘制统一下发、全体像素共享的参数块）的字段要通过参数名访问（`u.u1.xy`），漏写 `u.` 时 MSL（Metal Shading Language，Metal 的着色语言）把 `u1` 当独立标识符去找。
  解法：逐个字段检查 `u.` 前缀；着色器报错行号会直接指向出错的那一行。
- **图是歪的/拉伸的**：现象是横竖比不对。原因：归一化时 x、y 除以了同一个数（如都除以高度），宽屏会被横向拉长。解法：uv 各分量同除短边（`min(res.x, res.y)`），或分别除以对应边长并接受密度差异。

**Q：为什么扭曲要做两次（q 和 r），一次不够吗？**
一次扭曲把直线揉成波浪，纹理仍是"波纹"；两层嵌套后波纹自身的走向也被扭动，才出现大小漩涡嵌套的大理石质感。strength 越大纹路越碎，3~4 是本配方的舒适区。

**Q：想让图动起来怎么办？**
着色器参数里预留了 time：把它加进 p（如 `p + time * float2(0.1, 0)`），再按 plasma 实验（见 creative/01_plasma）的方式建 MTKView（MetalKit 提供的每帧渲染视图）每帧下发，纹理就会缓慢漂移。

**Q：怎么出一套风格统一的壁纸？**
固定 seed 之外的参数（scale、strength、调色三色），只扫 seed；或反过来固定 seed 微调 scale 出同构不同密度的系列。本实验的 export 命令已支持 seed 参数，脚本化批量只需一个 for 循环。
